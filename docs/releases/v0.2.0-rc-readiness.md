# v0.2.0 RC readiness

This checklist validates the `v0.2.0` release-candidate path from the current
guidance CLI surface. It is repo-local and non-mutating until a human explicitly
asks to publish the RC.

## Local Gates

Start from the intended release commit:

```sh
git status --short --branch
pnpm run check:runtime-prelude
pnpm run check:runtime-header
pnpm run check:runtime-substrate -- --details
pnpm run build
pnpm test
pnpm run build:release
```

Stop on any failing gate. Generated C warnings are not release blockers unless
the command exits non-zero.

`pnpm test` includes the `runtime_prelude_intrinsic_boundary_guard` smoke
contract for the compiler-owned `runtime/prelude.ts` intrinsic boundary. Keep
that evidence distinct from `pnpm run check:runtime-substrate -- --details`,
which proves the 56-symbol `runtime/runtime.h` substrate saturation and lane
counts.

## RC Tag Guard

Use the intended RC tag and compare it with the current `HEAD` without creating,
moving, deleting, or pushing the tag:

```sh
tag="v0.2.0-rc.1"
head="$(git rev-parse HEAD)"
if git rev-parse -q --verify "${tag}^{commit}" >/dev/null; then
  tag_head="$(git rev-parse "${tag}^{commit}")"
  if [[ "${tag_head}" != "${head}" ]]; then
    echo "STALE TAG: ${tag} points at ${tag_head}, not HEAD ${head}" >&2
    exit 1
  fi
else
  echo "MISSING TAG: ${tag} does not exist yet; do not create it in this checklist." >&2
fi
```

Do not push a tag, force-move a tag, delete a tag, trust an unrelated draft
Release, or silently switch to another release vehicle from this checklist.
Do not publish a GitHub Release unless the user explicitly asks to publish the
RC after the local readiness evidence has been reviewed.

## Downloaded Artifact Validation

After a separately published RC draft has produced assets, copy or download only
the artifact and checksums into a temporary directory and validate them there:

```sh
shasum -a 256 -c SHA256SUMS
chmod +x ./topaz-darwin-arm64
./topaz-darwin-arm64 --help

mkdir -p guidance-smoke
cat > guidance-smoke/effectful.ts <<'EOF'
import { readFileSync, writeFileSync } from "std/fs";
import { writeStdout } from "std/process";

const text = readFileSync("guidance-smoke/input.txt", "utf8");
writeFileSync("guidance-smoke/out.txt", text);
writeStdout(text);
EOF
printf 'hello from guidance\n' > guidance-smoke/input.txt

./topaz-darwin-arm64 doctor guidance-smoke/effectful.ts
./topaz-darwin-arm64 manifest init guidance-smoke/effectful.ts
./topaz-darwin-arm64 manifest init --write guidance-smoke/effectful.ts
./topaz-darwin-arm64 check guidance-smoke/effectful.ts
./topaz-darwin-arm64 explain capability fs.read
./topaz-darwin-arm64 explain std/fs
```

Expected guidance observations:

- `--help` lists `doctor`, `check`, `manifest init`, and `explain`.
- `doctor` reports `fs.read`, `fs.write`, and `io.stdout`.
- `manifest init` previews normalized `{ "capabilities": [...] }` policy text
  without writing.
- `manifest init --write` creates entry-adjacent `strict-ts.json` only when it
  is absent.
- `check` reports `missing capabilities: none` and `status: ok`.
- `explain capability fs.read` describes `fs.read`.
- `explain std/fs` describes `std/fs`.

## Out Of Scope

This RC readiness checklist does not change compile-time policy enforcement,
runtime sandboxing, schema expansion, richer policy discovery, CLI behavior,
manifest schema, artifact names, checksum format, package version, tags, GitHub
Releases, runtime, prelude, or generated header content.
