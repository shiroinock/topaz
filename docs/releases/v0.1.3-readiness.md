# v0.1.3 final readiness

This checklist separates local validation from human-owned release mutation for
the `v0.1.3` runtime TS prelude checkpoint. Run it immediately before trusting
any final `v0.1.3` tag, draft Release, assets, or release notes.

## Local Gates

Start from the intended release commit and a clean tree:

```sh
git status --short --branch
pnpm run build
pnpm test
pnpm run build:release
```

These commands do not push tags, edit GitHub Releases, or publish anything.
They prove only that the checkout can build, pass the normal smoke suite, and
produce the local release artifact set.

## Tag Head Guard

Before pushing, trusting, or using an existing final release tag, compare the
tag with the current `HEAD`:

```sh
tag="v0.1.3"
head_commit=$(git rev-parse HEAD)
tag_commit=$(git rev-parse "${tag}^{commit}")

if [[ "${tag_commit}" != "${head_commit}" ]]; then
  echo "STALE TAG: ${tag} points at ${tag_commit}, not HEAD ${head_commit}" >&2
  echo "Stop. Do not push a stale tag, trust a stale draft Release, force-move a remote tag, delete a remote tag, or auto-publish." >&2
  exit 1
fi
```

If the existing `v0.1.3` tag does not peel to the current `HEAD`, stop. Do not
push the stale tag, trust the draft Release, force-move or delete any remote
tag, or auto-publish the GitHub Release. Ask for explicit human direction
before changing release state.

## Downloaded Artifact Validation

After the human-owned tag push has produced a draft Release, download
`topaz-darwin-arm64` and `SHA256SUMS` into a temporary directory and validate
only the downloaded files:

```sh
shasum -a 256 -c SHA256SUMS
chmod +x ./topaz-darwin-arm64
./topaz-darwin-arm64 <repo>/examples/fib.ts -o ./fib
./fib
```

`fib` should print `5702887`.

Then run the v0.1.3 runtime-prelude fixture with the downloaded artifact:

```sh
cat > runtime-prelude-smoke.ts <<'EOF'
const label = "xxprelude".slice(2) + "+" + "check";
console.log(label);
console.log("prelude".charCodeAt(0));
console.log(label.startsWith("prelude"));
EOF

./topaz-darwin-arm64 runtime-prelude-smoke.ts -o ./runtime-prelude-smoke
./runtime-prelude-smoke
```

The expected output is:

```txt
prelude+check
112
true
```

## Human-Owned Release Actions

Only after the local gates, Tag Head Guard, checksum, fib smoke, and
runtime-prelude smoke are current and reviewed, a human operator may decide
whether to perform external release actions:

```sh
gh release edit v0.1.3 --notes-file docs/releases/v0.1.3.md
```

Applying notes is not publication. Keep the GitHub Release draft until the
assets, checksum, release notes, known limitations, and no-public-surface
boundary have been reviewed. Do not auto-publish a non-draft release from
Codex.
