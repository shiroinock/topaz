v0.1.3 is the runtime TS prelude checkpoint for the Topaz single-binary MVP line.

## Changes

- Embedded the internal runtime prelude path and stabilized hidden helper
  migration as release-checkpoint behavior for the native compiler artifact.
- Covered migrated pure helper families at a high level, including string,
  path, and bigint helper families, without expanding the public language
  surface.
- Kept runtime header / runtime prelude freshness checks and the runtime
  substrate inventory gate in the normal and release validation path.
- Added self-host, copied-artifact, and downloaded-artifact smoke coverage for
  the v0.1.3 runtime-prelude binary-only fixture.
- Preserved existing public CLI, language subset, artifact names, checksum
  format, and runtime semantics.

## Assets

- `topaz-darwin-arm64`: native Topaz compiler for Apple Silicon macOS.
- `SHA256SUMS`: checksum file for the compiler asset.

## Verification

After downloading the release assets into a temporary directory, verify the
checksum and generic single-binary smoke:

```sh
shasum -a 256 -c SHA256SUMS
chmod +x ./topaz-darwin-arm64
./topaz-darwin-arm64 <repo>/examples/fib.ts -o ./fib
./fib
```

The checksum should pass and `fib` should print `5702887`.

Then verify the v0.1.3 runtime-prelude checkpoint with a temporary fixture:

```sh
cat > runtime-prelude-smoke.ts <<'EOF'
const label = "xxprelude".slice(2) + "+" + "check";
console.log(label);
console.log("prelude".charCodeAt(0));
console.log(label.startsWith("prelude"));
EOF

./topaz-darwin-arm64 runtime-prelude-smoke.ts -o ./runtime-prelude-smoke
./runtime-prelude-smoke
```

The expected runtime-prelude output is:

```txt
prelude+check
112
true
```

## Notes

This release does not expand the public language surface or runtime semantics.
It is a release-readiness checkpoint for the embedded runtime TS prelude and
the remaining pre-v0.2 C substrate boundary. The compiler binary does not
require Node.js, pnpm, or a checked-out `runtime/` directory. It still invokes
the platform C compiler (`cc`) when producing native output.
